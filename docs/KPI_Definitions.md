# KPI Definitions

| KPI | Definition |
|---|---|
| Average Approval Days | Average days between application date and approval date. |
| Approval SLA % | Percentage of loans approved within two days. |
| Verification Success % | Percentage of verification records with KYCStatus = Verified. |
| Reconciliation Accuracy % | Percentage of payments with ReconciliationStatus = Matched. |
| Exception Backlog | Open or in-progress exceptions not yet resolved. |
| Delinquency Rate | Investor-reported delinquency percentage by month. |
