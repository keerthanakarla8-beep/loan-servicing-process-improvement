# Loan Servicing Process Improvement – Business Analyst Portfolio

## 📌 Project Overview

This repository demonstrates an end-to-end Business Analyst project for a fictional UK digital lender, **LendWise Finance UK**.

The project focuses on improving the loan servicing lifecycle from application intake through verification, underwriting, loan setup, payments, exception management and investor reporting.

The project follows a structured Business Analysis lifecycle:

**Business Problem → Requirements → Process Improvement → Validation → Reporting**

---

## 🎯 Business Problem

The existing loan servicing process contains several operational challenges:

- Manual verification activities
- Duplicate data entry
- Long approval cycles
- Reconciliation discrepancies
- Delayed investor reporting
- UAT defects
- Poor exception ownership and tracking

These issues create operational inefficiencies, increase manual effort and reduce process visibility.

# 3️⃣ Process Improvement

The AS-IS process was redesigned into a streamlined TO-BE process.

### Target TO-BE Process

**Digital Application**

↓  

**KYC API & Duplicate Check**

↓  

**Affordability Rules**

↓  

**Automated Decision / Manual Review**

↓  

**Automated Loan Setup**

↓  

**Daily Payment Reconciliation**

↓  

**Exception Queue with SLA**

↓  

**Daily Investor Reporting & Power BI**

### Key Improvements

- Reduce manual verification
- Minimise duplicate data entry
- Introduce automated validation
- Improve exception ownership
- Establish SLA-based exception management
- Improve payment reconciliation
- Enable timely investor reporting
